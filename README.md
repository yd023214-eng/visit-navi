# 방문지 순회 내비

엑셀에 적힌 여러 주소를 "내 현재 위치에서 가장 효율적인 순서"로 방문하도록 도와주는 단일 페이지 웹앱입니다.
실제 운전 안내는 네이버지도/카카오맵/카카오내비 앱에 맡기고, 이 앱은 순서 계산·내비 연결·진행 관리만 담당합니다.

- 서버 없음. `index.html` 하나로 동작합니다.
- 엑셀 파싱: SheetJS 0.20.3 (CDN)
- 지도·주소 변환: 카카오맵 JavaScript SDK (`libraries=services`)
- 카카오내비 연결: 카카오 JavaScript SDK 2.8.3 (선택 시에만 불러옴)

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 엑셀 업로드 → 주소 → 좌표 → 번호 핀 표시, 실패 목록 재시도, 중복 좌표 알림 | 완료 (테스트 통과) |
| 2 | 출발지(GPS/주소) → 방문 순서 계산(직선/도로) → 지도 경로선·순서 목록·드래그 정렬 → 내비 앱 연결 | 완료 (테스트 통과) |
| 3a | 하루 방문 수 제한, 오늘/다음날 분리, 완료·건너뛰기, 회색 처리, 진행 저장, 재계산, 처음부터 다시 | 완료 (테스트 대기) |
| 3b | HTTPS 배포 (GitHub Pages) + 카카오 콘솔 도메인 등록 | 완료 |

## 로컬 실행

`visit-navi` 폴더에서:

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 <http://localhost:8766> 접속.

## 2단계 테스트 방법

### PC에서 (순서 계산까지)

1. 엑셀 업로드 → 변환까지는 1단계와 같습니다. 변환이 끝나면 "출발지 / 방문 순서 계산" 카드가 나타납니다.
2. **출발지**: [현재 위치 사용]을 누르면 브라우저가 위치 권한을 묻습니다. 허용하면 지도에 초록색 "출발" 핀이 찍힙니다.
   - 거부했거나 PC라 위치가 부정확하면 아래 칸에 출발 주소를 넣고 [주소로 설정].
3. **방문 순서 계산**: 기본은 직선거리입니다. [방문 순서 계산]을 누르면
   - 지도 핀 번호가 **방문 순서**로 바뀌고 파란 선으로 연결됩니다.
   - "방문 순서" 카드에 목록과 구간 거리가 나오고, 맨 위에 초록색 [다음 목적지 안내] 버튼이 뜹니다.
   - "마지막에 출발지로 복귀"를 켜고 다시 계산하면 선이 출발지로 돌아옵니다.
4. **순서 바꾸기**: 목록의 ▲▼ 버튼, 또는 ≡ 를 누른 채 끌어서 옮깁니다. 바꾸면 지도와 거리도 바로 갱신됩니다.
5. **도로 거리 옵션**(선택): 거리 계산 방식을 "도로 거리"로 바꾸면 REST API 키 입력칸과 예상 호출 수가 나옵니다.
   카카오 개발자 콘솔 → [앱 설정] → [플랫폼 키] → REST API 키를 넣고 계산하면 됩니다.
   브라우저에서 직접 호출이 막히면 자동으로 직선거리로 대신 계산하고 그 사실을 표시합니다.

### 휴대폰에서 (내비 앱 열기)

PC의 `localhost` 주소는 휴대폰에서 열리지 않습니다. 3단계에서 HTTPS 주소로 배포한 뒤에 휴대폰 테스트가 가능합니다.
그 전에 미리 확인하고 싶다면 PC에서 [다음 목적지 안내]를 눌러 보세요. 열릴 URL이 안내창에 표시됩니다.

배포 후 휴대폰에서는:
1. 설정에서 "길 안내에 쓸 앱"을 고릅니다 (네이버지도 / 카카오맵 / 카카오내비).
2. [다음 목적지 안내]를 누르면 해당 앱이 열리며 목적지까지 경로가 잡힙니다. 앱이 없으면 설치 화면으로 갑니다.
3. 순서 목록의 각 항목에도 [여기로 안내] 버튼이 있습니다.

## 3단계(진행 관리) 테스트 방법

1. "방문 순서 계산" 카드에서 **하루에 방문할 곳 수**(기본 7)를 정하고 [방문 순서 계산].
   - "오늘 방문 순서"에 앞 N곳, "다음날 이후"에 나머지가 나뉩니다. 지도에서 오늘 핀은 파란색, 다음날 핀은 흰색 테두리입니다.
2. 맨 위 카드의 [✓ 이곳 완료]를 누르면 그 곳이 회색 ✓ 핀으로 바뀌고 다음 목적지로 넘어갑니다.
   - [건너뛰기]는 오늘 목록에서 빼서 다음날 이후 맨 앞에 둡니다.
   - 다음날 목록의 [오늘로 올리기]로 오늘 계획에 추가할 수 있습니다.
   - "완료한 곳" 목록에서 [완료 취소]로 되돌릴 수 있습니다.
3. 브라우저를 닫았다가 다시 열어도 데이터·순서·완료 표시가 그대로 복원됩니다 (같은 브라우저에 한함).
4. 다음날에는 [현재 위치에서 남은 곳 다시 계산]을 누르면 완료한 곳을 뺀 나머지로 새 계획을 만듭니다.
   전날 계획이 남아 있으면 상단에 "⚠ 날짜에 만든 계획입니다" 경고가 뜹니다.
5. [처음부터 다시]는 확인창 후 완료 표시와 순서를 지웁니다. 주소 데이터는 남습니다. 새 엑셀을 올리면 전부 초기화됩니다.

## 폴더 구성

```
  README.md
```

## 사용하는 외부 서비스와 한도 (2026-09-20 공식 문서 기준)

| 용도 | 서비스 | 한도/조건 |
|---|---|---|
| 지도·주소→좌표 | 카카오맵 JS SDK | 웹 SDK 일 300,000건. 계정의 첫 활성화 앱만 무료 |
| 도로 거리(옵션) | 카카오모빌리티 다중 목적지 길찾기 | 일 10,000건 무료, 초과 시 차단. 목적지 30개/호출, 반경 10km |
| 내비 열기 | 네이버지도 URL 스킴 `nmap://route/car` | appname 필수(웹은 페이지 주소). 안드로이드는 intent URL |
| 내비 열기 | 카카오맵 URL 스킴 `kakaomap://route` | 미설치 시 `m.map.kakao.com/scheme/…` 로 대체 |
| 내비 열기 | 카카오내비 `Kakao.Navi.start` | JS SDK 2.8.3, 휴대폰 전용, 미설치 시 설치 페이지 |
