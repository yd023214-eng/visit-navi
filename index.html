방문 순서 계산

도로 거리 방식 준비 방법
  1. 카카오 개발자 콘솔 → 같은 앱 → [앱 설정] → [플랫폼 키] → REST API 키 복사
  2. API 호출은 "출발지+방문지 수"만큼 발생하며 일 10,000건까지 무료입니다. 초과하면 그날은 차단됩니다.
  3. 출발지에서 10km 밖에 있는 곳은 API가 거리를 주지 않아, 그 구간은 직선거리×1.3으로 대신 계산합니다.
  4. REST 키는 이 브라우저에만 저장되지만, 웹페이지에서 쓰는 키이므로 3단계 배포 시 도메인 제한 설정을 안내해 드립니다.
직선거리 방식은 강·바다·산 때문에 도로가 크게 우회하는 곳에서는 순서가 비효율적일 수 있습니다. 결과 목록에서 드래그로 순서를 바꿀 수 있습니다.
