1. 처음 한 번만 하는 준비

1-1. 앱 주소를 휴대폰 홈 화면에 추가

앱 주소: https://yd023214-eng.github.io/visit-navi/

안드로이드 (크롬)
  1. 크롬으로 위 주소를 엽니다.
  2. 오른쪽 위 ⋮ → 홈 화면에 추가 → 추가
아이폰 (사파리)
  1. 사파리로 위 주소를 엽니다. (크롬이 아니라 사파리여야 합니다)
  2. 아래 가운데 공유 ⬆ → 홈 화면에 추가 → 추가
홈 화면 아이콘으로 열면 일반 앱처럼 쓸 수 있습니다. 입력한 키와 진행 상태는 그 휴대폰의 그 브라우저에 저장됩니다. 다른 휴대폰이나 다른 브라우저에서는 처음부터 다시 설정해야 합니다.

1-2. 카카오 JavaScript 키 넣기

지도를 보여 주고 주소를 좌표로 바꾸려면 카카오 키가 필요합니다. 앱 맨 위 설정 · 카카오 키 / 내비 앱을 눌러 펼친 뒤, 키를 붙여넣고 저장을 누르면 지도가 나타납니다.

키를 관리자에게 받는 경우

같은 회사·팀에서 이미 쓰고 있다면 관리자에게 "카카오 JavaScript 키"를 받아 넣으면 됩니다. 이 키는 앱 주소에서만 동작하도록 묶여 있어서 팀 안에서 함께 써도 괜찮습니다.

직접 발급하는 경우
  1. developers.kakao.com 에 카카오 계정으로 로그인 → 내 애플리케이션 → 애플리케이션 추가하기. 앱 이름·회사명(개인이면 본인 이름)·카테고리·대표 도메인(https://yd023214-eng.github.io)을 넣고 저장.
  2. 만든 앱 → 제품 설정 → 카카오맵 → 사용 설정 ON. (카카오맵 메뉴가 안 보이면 계정에 다른 앱이 이미 있어서 그런 것입니다. 카카오맵을 켠 첫 앱만 무료라서, 그 앱을 쓰세요.)
  3. 앱 설정 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 https://yd023214-eng.github.io 등록.
  4. JavaScript 키를 복사해 앱의 설정 칸에 붙여넣고 저장.
설정 안의 연결 테스트를 누르면 키가 제대로 동작하는지 바로 확인할 수 있습니다. "정상"이 나오면 끝.

1-3. 길 안내에 쓸 앱 고르기

같은 설정 카드에서 네이버지도 / 카카오맵 / 카카오내비 중 휴대폰에 설치된 앱을 고릅니다. 나중에 언제든 바꿀 수 있습니다.

1-4. (선택) 도로 거리로 계산하고 싶다면

기본은 직선거리로 순서를 정합니다. 강이나 산을 크게 돌아가는 지역이라면 "도로 거리" 방식이 더 정확합니다. 이때는 카카오 콘솔의 앱 설정 → 플랫폼 키 → REST API 키를 하나 만들어(허용 IP는 비워 둡니다) 앱의 "거리 계산 방식 → 도로 거리" 아래 칸에 넣으면 됩니다. 하루 10,000번까지 무료이고, 주소 100곳을 한 번 계산하면 약 400번을 씁니다.

2. 엑셀 파일 만드는 법

엑셀(.xlsx)의 첫 번째 시트, 첫 행에 열 이름이 있고, 그 아래로 한 줄에 한 곳씩 적으면 됩니다.

순번업체명주소담당자전화번호메모
1○○상사전남 순천시 서면 산단3길 25김민수010-1234-5678오전 방문
2△△마트광주 북구 첨단과기로 123 2층이서연062-123-4567주차 어려움
  • "주소"라는 글자가 들어간 열은 꼭 있어야 합니다. (예: 주소, 배송주소, 사업장주소) 없으면 앱에서 직접 고를 수 있습니다.
  • 업체명·담당자·전화번호·메모 열은 있으면 화면에 같이 보여 줍니다. 열 이름은 자유롭게 써도 됩니다.
  • 열이 더 있어도 됩니다. 모든 열을 기억해 두었다가 "핀에 표시할 열"에서 골라 볼 수 있습니다.
주소는 이렇게 쓰면 잘 찾습니다: "시/군/구 + 도로명 + 건물번호" (예: 순천시 서면 산단3길 25) 또는 "동/리 + 번지". 층·호수·괄호 안 설명이 붙어 있어도 앱이 알아서 걷어내고 찾습니다. 번지가 한두 개 틀려도 인근 번지로 찾아 주되 노란색으로 표시해 알려 줍니다.

3. 매일 사용하는 순서

① 엑셀 올리기

  1. 파일 선택을 눌러 엑셀 파일을 고릅니다. (카카오톡·메일로 받은 파일도 "파일" 앱이나 "다운로드"에서 고르면 됩니다)
  2. "열 선택" 카드가 나타납니다. 주소 열·업체명 열·담당자 열·메모 열이 맞게 잡혔는지 확인합니다.
  3. "핀에 표시할 열"에서 현장에서 보고 싶은 열을 체크합니다. "핀 색상 기준 열"에 담당자 같은 열을 고르면 사람별로 핀 색이 달라집니다. 이 선택은 기억됩니다.
  4. 주소 → 좌표 변환하고 지도에 표시를 누릅니다. 잠시 기다리면 지도에 번호 핀이 찍힙니다.

② 못 찾은 주소 고치기

"변환 실패" 카드에 못 찾은 주소가 나옵니다. 주소를 고쳐 쓰고 다시 시도를 누르면 됩니다. 보통 시/군 이름이 빠졌거나 오타가 있는 경우입니다.

"중복 좌표" 카드는 같은 위치가 두 줄 이상 있다는 뜻입니다. 잘못 넣은 게 아니라면 그냥 두어도 됩니다.

③ 출발지 정하기

세 가지 방법 중 하나를 씁니다.

  • 현재 위치 사용: 휴대폰이 위치 권한을 물으면 허용합니다. 지도에 초록색 "출발" 핀이 찍힙니다.
  • 올린 목록에서 찾기: 지금 어느 거래처에 와 있다면, 검색칸에 업체명·담당자·전화번호 일부(예: 1234)를 치고 나오는 항목을 탭합니다. 그 곳이 출발지가 되고 오늘 1번 목적지로 잡히니, 이미 도착해 있으면 ✓ 이곳 완료를 누르면 됩니다.
  • 주소 직접 입력: 아래 칸에 출발 주소를 적고 주소로 설정.

③-2 복귀 장소 정하기 (한 번만)

"복귀 장소" 카드에서 지정한 장소로 복귀를 고른 뒤, 목록에서 찾거나 집·사무실 주소를 적고 주소로 설정. 한 번 지정하면 다음날에도 기억합니다. 오늘 마지막 방문지에서 이곳까지의 거리가 계산에 들어가고, 지도에 보라색 "복귀" 핀이 찍힙니다. 오늘 계획을 다 마치면 큰 버튼이 복귀 장소로 안내로 바뀝니다.

"출발지로 복귀"를 고르면 아침에 출발한 곳으로 돌아오고, "복귀 안 함"이면 마지막 방문지에서 끝납니다.

④ 오늘 방문 순서 계산

  1. "순서 정하는 방식"은 기본이 지금 위치에서 가까운 곳부터 차례로입니다. 매번 지금 있는 곳에서 가장 가까운 곳으로 갑니다. "하루 전체 이동거리가 가장 짧게"를 고르면 복귀 장소까지 포함해 총 거리가 짧아지도록 순서를 섞습니다.
  2. "하루에 방문할 곳 수"를 정합니다. (예: 7) 나머지는 자동으로 "다음날 이후"로 넘어갑니다.
  3. 방문 순서 계산을 누릅니다. 지도 핀 번호가 방문 순서로 바뀌고 파란 선으로 이어집니다.
  4. 순서를 바꾸고 싶으면 목록의 ▲▼ 버튼을 누르거나, ≡를 누른 채 끌어서 옮깁니다.

⑤ 이동 → 도착 → 완료, 반복

  1. 맨 위의 큰 초록 버튼 다음 목적지 안내를 누릅니다. 내비 앱이 열리며 경로가 잡힙니다.
  2. 도착해서 볼일을 본 뒤 이 앱으로 돌아와 ✓ 이곳 완료를 누릅니다. 그 곳은 회색 ✓ 핀이 되고, 버튼이 다음 목적지로 바뀝니다.
  3. 오늘 못 갈 곳은 건너뛰기. 다음날 목록 맨 앞으로 갑니다.
  4. 핀을 탭하면 정보 카드가 올라옵니다. 전화번호를 탭하면 바로 전화가 걸리고, 아래 칸에 현장 메모를 적으면 자동 저장됩니다.
내비 앱에 갔다가 돌아오거나 브라우저를 껐다 켜도 진행 상태는 그대로 남아 있습니다.

⑥ 다음날 아침

앱을 열고 현재 위치에서 남은 곳 다시 계산을 누르면, 완료한 곳을 뺀 나머지로 오늘 계획을 새로 만듭니다. 이걸 남은 곳이 없을 때까지 반복합니다.

⑦ 결과 정리

"결과 내보내기" 카드의 결과 엑셀 내보내기를 누르면 원래 엑셀에 방문순서 · 완료여부 · 완료시각 · 현장메모 열이 붙은 파일이 내려받아집니다.

새 엑셀을 올리면 이전 데이터는 지워지니, 필요하면 먼저 내보내 두세요.

4. 화면과 버튼 설명

지도 핀 색깔

파란 핀 (숫자)오늘 방문할 곳. 숫자는 방문 순서.
흰 바탕 파란 테두리다음날 이후에 갈 곳.
회색 ✓완료한 곳.
노란 핀주소를 정확히 못 찾아 인근 주소나 비슷한 장소로 대체한 곳. 위치를 한 번 확인하세요.

"핀 색상 기준 열"을 고르면 파란 핀 대신 값별 색이 쓰이고, 지도 왼쪽 위에 범례가 뜹니다.

주요 버튼

버튼하는 일
다음 목적지 안내내비 앱을 열어 다음 곳으로 안내. 버튼에 "다음: 이름 · 오늘 남은 곳 N개"가 표시됨. 오늘 계획을 다 마치면 복귀 장소로 안내로 바뀜.
✓ 이곳 완료지금 목적지를 완료 처리(회색)하고 다음으로 넘어감.

완료 취소실수로 완료한 곳을 되돌림. "완료한 곳" 목록에 있음.
현재 위치에서 남은 곳 다시 계산완료한 곳을 빼고 지금 위치 기준으로 순서를 새로 계산. 순서가 틀어졌을 때나 다음날 아침에.
처음부터 다시완료 표시와 순서를 모두 지움(주소는 남음). 확인창이 뜸.
여기로 안내순서와 상관없이 그 곳으로 바로 내비 열기. 목록과 핀 정보 카드에 있음.

5. 자주 생기는 문제와 해결

지도가 안 뜨고 "불러오지 못했습니다"가 나와요
  • 키를 잘못 붙여넣었거나(앞뒤 공백 포함), 카카오 콘솔에서 카카오맵 사용 설정이 꺼져 있거나, JavaScript SDK 도메인에 앱 주소가 등록되지 않은 경우입니다. 1-2를 다시 확인하세요.
  • 설정의 연결 테스트가 원인을 알려 줍니다.
"현재 위치 사용"이 안 돼요
  • 위치 권한을 "거부"했다면: 휴대폰 설정 → 브라우저(크롬/사파리) → 위치 → 허용으로 바꾸고 다시 시도.
  • 실내에서는 위치가 늦게 잡힐 수 있습니다. 급하면 출발 주소를 직접 입력하세요.
내비 앱이 안 열려요
  • 그 앱이 설치돼 있는지 확인하세요. 없으면 설치 화면으로 넘어갑니다.
  • 설정에서 다른 앱(네이버지도 ↔ 카카오맵)으로 바꿔 보세요.
  • PC 브라우저에서는 내비 앱이 열리지 않습니다. 휴대폰에서 쓰세요.
주소가 "변환 실패"로 나와요
  • 시/군/구 이름을 앞에 붙이고, 도로명과 건물번호(또는 동과 번지)까지 적은 뒤 다시 시도.
  • 모든 주소가 한꺼번에 실패하면 주소 문제가 아니라 키/설정 문제입니다. 연결 테스트를 눌러 보세요.
어제 올린 데이터가 사라졌어요
  • 데이터는 같은 휴대폰의 같은 브라우저에만 저장됩니다. 다른 브라우저(예: 카카오톡 안에서 열기)로 열면 비어 보입니다. 홈 화면 아이콘으로 여는 습관을 들이세요.
  • 브라우저의 "인터넷 기록 삭제"에서 사이트 데이터를 지우면 함께 지워집니다.
순서가 이상해요 (강 건너편이 먼저 나와요)
  • 기본은 직선거리라 강·바다·산을 돌아가는 길은 반영되지 않습니다. 목록에서 손으로 순서를 바꾸거나, 1-4의 "도로 거리" 방식을 켜 보세요.

6. 알아 두면 좋은 것

  • 노란 핀은 꼭 확인. 번지가 없어 인근으로 대체한 곳은 실제 위치와 다를 수 있습니다. 핀을 탭하면 어떻게 찾았는지 이유가 나옵니다.
  • 키는 남에게 보내지 마세요. JavaScript 키는 앱 주소에서만 동작하도록 잠겨 있지만, REST API 키는 그렇지 않습니다.
